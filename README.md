# Long-history rows for the Meme-Bot (fake money only)

Derived from the Pumpfun Memecoin Corpus by Slinky21 (https://huggingface.co/datasets/Slinky21/Pumpfun_Memecoin_Corpus, MIT licence): the post-graduation snapshots of June and July 2026, sampled at whole hours after each coin's graduation (a snapshot within 600 s), with the price 1.7 hours later and the path over 6 hours. Built by research/history_build.py.
